Dead air
The whole import is one grey UIKit spinner and a sentence. Video imports transcribe the audio, so this can run 10 seconds or more with nothing to look at and no way out.
Not Glutt
Bare bullet lists, three system steppers stacked, an all caps INGREDIENTS label in SF Pro. None of the cream cards, food icon tiles or pantry chips the rest of the app is built from.
Invisible field
In the in app sheet the link field is filled with Theme.Colors.card inside a card that is already Theme.Colors.card, so the input has no visible edge and Import from link sits there looking enabled while disabled.
1b
It builds itself
The wait becomes the content. No spinner: the recipe card is on screen from the first frame and fills in as the pipeline works, ingredient rows dropping into place one at a time in real Glutt food icon tiles. You can leave whenever you want, because the import already finishes in the background through the import inbox.
